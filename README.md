# Next Interview Lab

A focused, hands-on TypeScript → React → Next.js interview practice track. Each mission gives you a realistic brief, a small set of TODOs, acceptance checks, and questions to answer aloud.

## Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Pick a mission, open its matching file in [`exercises/`](./exercises), implement the TODOs, and mark it cleared only after you can explain it.

Each mission has an **Open in VS Code** button. When you run the app locally, it resolves the exercise path from that clone's working directory and opens it in the installed desktop version of VS Code. It never uses the original author's file path.

## Suggested run-up to Monday

1. Do missions 01–03 today: TypeScript only, no React shortcuts.
2. Do missions 04–06 next: React and Next.js boundaries.
3. Do mission 07 in one timed sitting. Narrate your decisions as you work.

## The rule

Spend 15 minutes trying before searching. When you search, look up the smallest missing concept—not the whole solution. The final questions are deliberately phrased for speaking practice.
